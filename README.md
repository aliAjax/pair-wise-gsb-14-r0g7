# 油品价格维护 · 基准价联动与批零价差审签台

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript（不新增依赖，数据保存在浏览器 localStorage）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 功能闭环

- **调价登记**：每笔调价选择区域、油品、基准价、加价幅度与生效时刻，新价 = 基准价 + 加价幅度；可多笔明细组成一个批次，整批校验、整批审批。
- **区间占用**：待审批 / 待生效批次按「区域+油品」占用自生效时刻起的未来区间，同区同油品不允许重叠占用；生效前撤回立即释放占用。
- **价差审签**：批零价差低于保底毛利（0.30 元/升）或相对旧价涨跌幅超过当日限制（±5%）时，整批留草稿，并逐条列出旧价、新价与触发规则。
- **按期生效**：审批通过后到达生效时刻自动生效（页面每 10 秒推进一次时钟，刷新时也会补推）。
- **版本留痕**：已生效批次不可修改；改价只能新建带调价原因的版本，旧价快照与完整审批链随历史保留。

## 代码分层（规则 / 存储 / 页面分离）

- `src/domain/` — 类型（`types.ts`）、业务配置（`config.ts`）、纯函数规则引擎（`rules.ts`：占用与重叠判定、保底毛利与涨跌幅校验、按期生效推进）。
- `src/storage/store.ts` — localStorage 持久化与响应式状态，批次为唯一事实来源，台账 / 队列 / 占用均由其推导，刷新后队列与历史一致。
- `src/components/` — 页面：`BatchForm.vue`（调价表单+预检）、`ReviewDesk.vue`（审签台：审批队列+草稿箱）、`HistoryLog.vue`（价格台账+历史版本与审批链）。
