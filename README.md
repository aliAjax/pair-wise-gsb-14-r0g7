# 油品价格维护 · 基准价联动与批零价差审签台

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript（在原最小闭环上扩展，未新增依赖）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务闭环

1. **新建调价批次**：每笔明细选择区域、油品、基准价、加价幅度与生效时刻，零售牌价 = 基准价 + 加价幅度（批零价差）。
2. **提交审签时规则引擎整批校验**：
   - 同区同油品生效区间不得重叠（生效时刻与已占用区间冲突）；
   - 加价幅度不得低于保底毛利（默认 0.35 元/升）；
   - 相对生效时刻在册旧价的涨跌幅不得超过当日上限（默认 ±4%）。
   触发任一条 → **整批留草稿**，并列出新价、旧价与触发规则；草稿可在线修正后重新提交。
3. **审批通过后按期生效**：明细进入待生效队列并占用生效区间，到点自动生效（页面每 30 秒巡检，刷新时立即补齐）。
4. **生效前撤回释放占用**：待生效明细可撤回，占用区间即时释放。
5. **生效后改价只能新建带原因版本**：从牌价页发起改价，原因必填，重新走审签；旧值与审批链全程保留在版本历史中。

## 目录结构（规则 / 存储 / 页面分离）

- `src/domain/types.ts`：领域模型、状态与文案字典
- `src/domain/rules.ts`：规则配置（`RULES`）与整批校验引擎（纯函数）
- `src/data/store.ts`：localStorage 持久化与种子数据
- `src/state/desk.ts`：响应式状态、批次/明细动作与派生队列
- `src/components/`：页面组件（批次录入、审签队列、牌价与版本）

数据保存在浏览器 localStorage（键 `dfwlfront-9-price-desk-v1`），刷新后审签队列与版本历史保持一致。
